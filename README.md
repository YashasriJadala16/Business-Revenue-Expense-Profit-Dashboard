# Business Revenue, Expense & Profit Analysis Dashboard

## 📊 Project Overview

The **Business Revenue, Expense & Profit Analysis Dashboard** is a
Microsoft Excel-based data analytics project created to transform raw
business transaction data into a clear and interactive visual dashboard.

The project analyzes **2,000 business transactions** across revenue,
expenses, profit, payment methods, product lines, regions, departments,
and business categories.

The dashboard provides a consolidated view of business performance and
helps identify important financial and operational patterns.

------------------------------------------------------------------------

## 🎯 Project Objectives

-   Analyze total revenue, expenses, and profit.
-   Compare profit generated through different payment methods.
-   Analyze revenue performance across product lines.
-   Understand transaction activity across different regions.
-   Compare average expenses across departments.
-   Analyze revenue, expenses, and profit by category.
-   Convert raw transaction data into meaningful business insights.
-   Build a professional Excel dashboard for business reporting.

------------------------------------------------------------------------

## 🗂️ Dataset Overview

The dataset contains **2,000 transaction records** and **12 columns**.

  Dataset Metric          Value
  --------------------- -------
  Transaction Records     2,000
  Columns                    12
  Categories                  5
  Departments                 6
  Product Lines               5
  Regions                     5
  Customer Segments           4
  Payment Methods             4

### Dataset Columns

  Column               Description
  -------------------- ----------------------------------------------
  `Transaction_ID`     Unique ID for each transaction
  `Transaction_Date`   Date of the transaction
  `Revenue`            Revenue generated by the transaction
  `Expenses`           Expenses associated with the transaction
  `Profit`             Profit or loss generated by the transaction
  `Category`           Business category
  `Region`             Geographical region
  `Department`         Department associated with the transaction
  `Product_Line`       Product line associated with the transaction
  `Customer_Segment`   Customer segment
  `Payment_Method`     Payment method used
  `Discount`           Discount applied to the transaction

## 📌 Key Performance Indicators (KPIs)

The dashboard contains three KPI cards displayed below the main
dashboard title.

  KPI                           Value
  -------------------- --------------
  **Total Profit**       ₹2,04,93,529
  **Total Revenue**      ₹5,39,65,575
  **Total Expenses**     ₹3,34,72,046

These KPIs provide a quick overview of the company's overall financial
performance.

**Profit Margin:** approximately **38.0%**, calculated as:

`Total Profit ÷ Total Revenue × 100`

## 📈 Dashboard Components

### 1. Total Profit by Payment Method

A column chart compares the total profit generated through different
payment methods:

-   PayPal
-   Bank Transfer
-   Credit Card
-   Cash

The chart helps understand how profit contribution varies across payment
methods.

### 2. Total Revenue by Product Line

A horizontal bar chart compares revenue across:

-   Software
-   Healthcare
-   Furniture
-   Electronics
-   Clothing

This visualization helps identify the major revenue-generating product
lines.

### 3. Number of Transactions by Region

An area chart shows transaction volume across:

-   Africa
-   Asia-Pacific
-   Europe
-   North America
-   South America

This provides a geographical view of transaction activity.

### 4. Average Expense for Each Category

The dashboard uses a pie chart to compare average expenses across:

-   Finance
-   HR
-   IT
-   Marketing
-   Operations
-   Sales

Although the chart title uses the word **Category**, the slices
represent **departments** in the source dataset.

### 5. Total Revenue / Expenses / Profit by Category

A line chart compares financial performance across business categories
using:

-   Revenue
-   Expenses
-   Profit

This helps compare financial performance from multiple perspectives
rather than looking at revenue alone.
